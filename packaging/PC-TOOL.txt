AnyController-Inspector.exe - PC-side helper
============================================

Windows tool for inspecting a controller from the PC. You do not need it to play.

Run it from Command Prompt or PowerShell (double-clicking closes the window):

    AnyController-Inspector.exe --list
    AnyController-Inspector.exe --live 15
    AnyController-Inspector.exe --play capture.txt

--list       shows attached HID/USB devices as VID:PID and says whether the
             payload can drive each one. Send this when reporting a new pad.
--live N     reads a pad in XInput mode and compares it with our decoder.
--play FILE  decodes a hex report dump (the "xcpcapture" lines the payload
             writes to its log).

Note: this build does not yet capture raw reports from an unknown controller.
For now, --list is what to send when reporting a new pad.
